# Truck Hisab

Clean application scaffold for the Truck Hisab product. Business modules and
database design will be added only after requirements are approved.

## Applications

- `backend/` — independent Express and TypeScript MVC API.
- `frontend/` — independent Next.js and TypeScript web application.

## Run locally

Open two terminals and install/run each application independently.

Backend:

```powershell
cd backend
npm install
npm run dev
```

Frontend:

```powershell
cd frontend
npm install
npm run dev
```

The backend defaults to `http://localhost:4000` and the frontend defaults to
`http://localhost:3000`.
